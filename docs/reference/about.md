# About Sygnal

Sygnal is an open way to build Care Coordination Networks: networks in which independent health platforms hand off care, follow each handoff through, and see where care falls through the gaps. See [Welcome to Sygnal](../README.md) for an overview.

## Who shapes the protocol

The **Sygnal Protocol** is shaped together, in the open. **Medtronic LABS** leads the work, with partners, implementers and the wider community. The specification and documentation are public: anyone can review them, use them and propose changes. See [How to give feedback](feedback.md).

## Who builds the platform

**Medtronic LABS** develops the **Sygnal Platform**, the open-source software that implements the protocol. Anyone will be able to run it once it is released.

## Who runs the hosted services

**Medtronic LABS** operates Sygnal Network Services today. The operator may change as network governance develops. See [Protocol, platform and services](../concepts/protocol-platform-services.md).

## Who looks after the standard

Medtronic LABS looks after the specification for now, on behalf of everyone who takes part. The intent is that no single organisation owns the standard: stewardship is meant to move to a neutral governance body as adoption grows. See [Network governance](../governance/README.md#stewarding-the-specification).
